# DLSS Nexus 1.1.0 — Choose your add-on and DLSS-NR versions

Nexus 1.1.0 gives you more control over your Neural Rendering setup. You can now choose the add-on and DLSS-NR runtime independently, including previous builds, instead of always using the newest bundled pair.

## What's new

- **Separate version selectors under Advanced.** Mix the current or previous ShortFuse add-on with either bundled DLSS-NR runtime for Standard DX11/DX12 setups.
- **Recognized installed choices are restored.** Reopening setup selects uniquely recognized installed versions, so keeping an older build does not silently become an upgrade.
- **Clearer Review and Ready information.** See the exact selected builds and whether the runtime will be installed, replaced or kept. If an existing DLL is being kept, Nexus explicitly says the selected alternative will not be installed.
- **Room for future releases.** The version catalog supports additional add-on and runtime builds without introducing a new setup profile for every release.

## Available versions

| Component | Default for new setups | Selectable previous build |
|---|---|---|
| ShortFuse add-on | `0.2026.1016.1704` | `0.2026.1003.2333` |
| DLSS-NR runtime | `310.9.16.0` — ShortFuse patched FP16 compatibility build | `310.8.0.0` — original NVIDIA-signed build |

The current builds remain the defaults for new setups. DX10 continues to use the Feeder helper with compatible Generic add-on choices; the ShortFuse alternatives are not DX10 add-ons. Legacy and Custom profiles remain available.

**Important:** DLSS-NR 310.8.0.0 is not the patched FP16 compatibility build. Do not assume it has the same RTX 20/30/40 support; GPU and driver requirements may differ. Image-quality preferences between builds are subjective—Nexus does not claim that an older version produces better results.

## How to switch versions

1. Close the game, select it in Nexus and choose **Set up**.
2. Open **Advanced**, then choose **Add-on version** and **DLSS-NR version**.
3. To change an existing add-on, enable **Replace existing add-ons**. To change an existing DLSS-NR DLL, also enable **Also replace the neural runtime**.
4. Choose **Review** and check the version labels and **Install / Replace / Keep** actions before confirming **Install**.

Selecting a version alone does not grant replacement permission. Replaced files are backed up whether you are upgrading or selecting an older build. Existing Super Resolution runtimes, custom settings and presets retain the normal Nexus preservation rules.

## Updating from 1.0.0

Close Nexus before running the **1.1.0 Windows installer**, or extract the **1.1.0 portable ZIP** into a new folder. Both include the .NET runtime; no separate .NET installation is needed.

Updating the Nexus application does **not** automatically change DLLs or add-ons in your games. Your saved library, game components and installation backups are retained. Use **Set up** when you want to change a game's component versions.
